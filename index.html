# Mustafa & Zainab — Wedding Invitation A mobile-first, animated wedding invitation microsite with a knock-to-open golden door experience. ## Run locally Open `index.html` in a browser, or run `python -m http.server 8080` from this folder. ## Deploy Static website. No build command is needed; the project root is the output directory. ## Features - Knock-to-open double door animation - Animated reveal and scrolling original invitation scans - Corrected wedding date: Tuesday 19th January 2027 - Responsive layout and reduced-motion support
